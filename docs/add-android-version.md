# 增加 Android 版本

当前只验证 AOSP 13。14、15 分别建立同层源码目录，不在一个目录里反复切大版本。

新增版本时先检查基础产品继承路径、模块构建属性、安装位置和工具 API。对 research-info 优先复用同一提交；有实际差异才添加目标配置或版本专属入口。

核心实验从对应新版本基线建立单独分支，再 cherry-pick 自己的少量提交。检查 ActivityManagerShellCommand 的入口与 Build.IS_DEBUGGABLE 条件，不能把提交应用成功当成语义正确。

每个版本执行完整镜像启动和相同设备验证。跨版本比较固定工具提交、设备架构和样例参数，并记录系统基线。

lab 当前明确只接受 aosp13。增加目标时，需要同时扩展目标选择、产品入口、构建与设备断言，并提交该版本的实测报告；不能仅修改 SDK 常量就宣称支持。
